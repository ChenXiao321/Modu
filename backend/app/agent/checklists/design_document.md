# 设计文档生成阶段检查表

本文档定义了软件详细设计规范生成 Agent 的质量检查项。

## 通用检查项（所有步骤）

- [ ] 输出格式为纯 JSON，无多余解释文字
- [ ] 输出中没有 Markdown 代码块标记（```json）

## 步骤 1 检查项（FC 识别）

- [ ] 每个 FC 有唯一的 fc_id
- [ ] 所有功能性需求都被分配到至少一个 FC
- [ ] ASIL-C/D 需求分配到独立或受保护的 FC
- [ ] 需求分配有明确的理由（allocation_rationale）

## 步骤 2 检查项（软件详细设计）

- [ ] 每个 FC 的外部接口完整定义（函数名、参数、返回值）
- [ ] 每个 FC 的内部接口完整定义（函数名、参数、返回值）
- [ ] 算法实现步骤具体、可验证
- [ ] ASIL-C/D 的 FC 包含冗余设计说明
- [ ] ASIL-C/D 的 FC 包含 FMEA 参考
- [ ] 圈复杂度目标：手写代码 < 15，模型开发 < 50
- [ ] 安全设计包含故障处理策略
- [ ] 验证策略包含单元测试覆盖率目标
